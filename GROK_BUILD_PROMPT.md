1. Pinned chats get pushed down; want a dedicated pinned section at the top.
2. Always-visible jump-to-top and jump-to-bottom arrows; labeled Search in this chat (current conversation only). Ctrl+F exists; not everyone knows it.
3. Sync: app → web is live; web → iOS needs app close/reopen.
4. Sidebar: icons-only is weak. Labels by default or toggle. Whole row clickable. Option for text-only.
5. Product naming: do not send people to the wrong product for coding. Grok = general assistant. Grok Build = coding agent. Later the field also has Grok Bot — same principle: say which tool is for what.
6. X profiles update: positive. “This is how it’s done.”
7. Shake to Report on iOS: off by default or drop the gesture. Putting the phone down should not open Report a Problem. User also says he did not read the sheet and did not ask for help; the Advanced Settings toggle was already there.
